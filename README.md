# Астро-Волга — областной хаб

Локальный статический сайт на HTML, CSS и JavaScript. Авторизация, формы и внешние JS-библиотеки отсутствуют.

## Запуск

Из папки проекта выполните:

```bash
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080`.

## Настройка

- Количество агентов внесено по таблице отдела маркетинга «списки агентов.xlsx» от 19.08.2026 и задаётся в объекте `cities` в `script.js`.
- Для подключения Яндекс Метрики добавьте официальный код счётчика и задайте `window.YM_COUNTER_ID`.
- Проверка геобаннера: `http://localhost:8080/?city=melitopol`.

Все фирменные изображения, логотип, favicon и шрифты сохранены локально в папке `assets`. Страницу также можно открыть двойным кликом по `index.html`, но локальный HTTP-сервер удобнее для разработки.
